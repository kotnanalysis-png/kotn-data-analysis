# KOTN auction bidding data review

Public report: https://azerax.github.io/KOTN/

Open `index.html` to review the evidence-based report. GitHub Pages should be set to publish from `main` at `/ (root)`.

Raw source exports live under `data/` and contain public auction usernames, bid amounts, IDs, and timestamps. Findings indicate unusual speed, not proven bots, fraud or operator affiliation.
