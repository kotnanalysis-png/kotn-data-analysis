Closing dates and overlap

Round membership comes from the listing scheduled_end value: October 18–19, October 25–26, November 1–2, and November 8–9. A bid’s submission date does not always match its associated listing closing round. The site has a two-minute bid-extension rule, so scheduled end should not be misinterpreted as final closing time.

Better benchmark design

High-frequency accounts were selected using rolling-minute speed, so their faster gap distribution is partly a selection effect. Match controls on number of bids, active-day coverage, closing window, category and available inventory; hold out later days for validation. Compare complete days, using the same predeclared thresholds each time.
