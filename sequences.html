Definition

A streak consists of three or more consecutive bids from the same account and closing cohort, with each adjacent gap at most one recorded second and each bid on a different listing. Listing IDs are provided so the sequence can be checked against the exported bids.

Distinct patterns to test

Some high-speed accounts appear to move through nearby listing identifiers; others jump larger numeric distances. Future analysis should reconstruct the actual catalogue ordering by auction and time, and compare with volume-matched accounts before interpreting this as manual navigation or automation.
